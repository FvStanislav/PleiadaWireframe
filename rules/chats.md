# Chat Rules

## Counterparty conversations

- `BR-CHT-001` — Both advertiser and publisher workspaces have a **Чаты** section.
- `BR-CHT-002` — Conversations are grouped by counterparty organization, independently of the number of channels, campaigns and placements managed by that organization.
- `BR-CHT-003` — Each counterparty has an **Общий чат** for messages not tied to a specific placement.
- `BR-CHT-004` — The counterparty section expands to show a list of placement-specific discussions. The organization is the primary grouping; placements are subordinate discussion contexts.
- `BR-CHT-005` — A placement mini-chat and that placement's entry in the main **Чаты** section open the same discussion, not separate copies.
- `BR-CHT-006` — A channel-level **Связаться** action opens the organization's general chat; a placement-level **Чат** action opens the placement discussion.
- `BR-CHT-007` — On the publisher side, **Связаться** on a placement request and **Чат по размещению** in the request detail open the same placement-linked discussion.
- `BR-CHT-008` — In this prototype, messages are stored only in browser-session memory and shared by the two workspaces while switching without reload. The counterpart organizations, participants and messages are mock fixtures; real messaging, permissions and persistence are not implemented.

Structured price/date negotiations and contracts are not defined by these chat UI rules.

# Format Rules

## Content format → platform → placement format → additional options matrix

- `BR-FMT-001` — **Длинные видео** supports platforms: **VK Video**, **YouTube**.
- `BR-FMT-002` — **Длинные видео** supports placement formats: **Видео рекламодателя**, **Нативный текст рекламодателя**, **Нативное объявление спонсора видео**.
- `BR-FMT-003` — **Длинные видео** supports additional options: **Конкурс (розыгрыш)**, **Ссылка в описании**, **Закрепленный комментарий**, **Эксклюзивность категории**.
- `BR-FMT-004` — **Short-form видео** supports platforms: **VK Clips**, **YouTube Shorts**, **TikTok**.
- `BR-FMT-005` — **Short-form видео** supports placement formats: **Баннер**, **Анимационный баннер**, **Half screen**.
- `BR-FMT-006` — **Short-form видео** supports additional options: **Описание**, **Закрепленный комментарий**, **Эксклюзивность категории**.
- `BR-FMT-007` — **Посты** supports platforms: **VK**, **Telegram**, **Max**.
- `BR-FMT-008` — **Посты** supports placement formats: **Пост**, **Репост**.
- `BR-FMT-009` — **Посты** supports additional options: **Перманентный пост**, **Эксклюзивность категории**.
- `BR-FMT-010` — **Наружная реклама** supports platform: **Наружная реклама**.
- `BR-FMT-011` — **Наружная реклама** supports placement formats: **Биллборд**, **Сити**, **Пиллар**, **Цифровой экран**.
- `BR-FMT-012` — **Наружная реклама** supports additional option: **Эксклюзивность категории**.

These are the current values for campaign-creation step 1. They may be extended or changed later without changing the step structure itself.

# Format Rules

## Content format → platform → placement format matrix

- `BR-FMT-001` — **Длинные видео** supports platforms: **VK Video**, **YouTube**.
- `BR-FMT-002` — **Длинные видео** supports placement formats: **Конкурс (розыгрыш)**, **Ссылка в описании**, **Закрепленный комментарий**, **Эксклюзивность категории**.
- `BR-FMT-003` — **Short-form видео** supports platforms: **VK Clips**, **YouTube Shorts**, **TikTok**.
- `BR-FMT-004` — **Short-form видео** supports placement formats: **Описание**, **Закрепленный комментарий**, **Эксклюзивность категории**.
- `BR-FMT-005` — **Посты** supports platforms: **VK**, **Telegram**, **Max**.
- `BR-FMT-006` — **Посты** supports placement formats: **Перманентный пост**, **Эксклюзивность категории**.
- `BR-FMT-007` — **Наружная реклама** supports platform: **Наружная реклама**.
- `BR-FMT-008` — **Наружная реклама** supports placement format: **Эксклюзивность категории**.

These are the current values for campaign-creation step 1. They may be extended or changed later without changing the step structure itself.

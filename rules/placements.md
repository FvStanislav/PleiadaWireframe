# Placement Rules

## Campaign creation — step 3: Сплит

- `BR-PLC-001` — Step 3 shows a **Сплит** of media placements selected for the campaign.
- `BR-PLC-002` — The step displays **Запланированный бюджет** and **Предварительный бюджет** as separate informational values.
- `BR-PLC-003` — Placements currently selected for the split are displayed as a list of media cards under **Подобрали для вас размещения**.
- `BR-PLC-004` — A media card shows: media name, subscribers, views, reach, ER, ERR, audience gender ratio, audience age distribution and publications per month.
- `BR-PLC-005` — A placement already included in the split has a green **Добавлено в сплит** button.
- `BR-PLC-006` — Clicking **Добавлено в сплит** removes the placement from the current prototype split state and changes the button to black **Добавить в сплит**.
- `BR-PLC-007` — Clicking **Добавить в сплит** adds the placement back and restores green **Добавлено в сплит** state.
- `BR-PLC-008` — No budget recalculation rule is defined yet for adding or removing placements; the prototype budget values remain informational until that behavior is specified.
- `BR-PLC-009` — Additional media that may fit the campaign are shown in a separate **Могут подойти** section.
- `BR-PLC-010` — Media in **Могут подойти** are not included in the split by default and therefore start with the black **Добавить в сплит** button.
- `BR-PLC-011` — **Могут подойти** has a search field by media name.
- `BR-PLC-012` — **Могут подойти** can be ordered by: **По релевантности**, **По подписчикам**, **По просмотрам**, **По цене**.
- `BR-PLC-013` — The prototype does not calculate whether media actually match the filters from step 2; the suggested list is fixed mock data used only to evaluate the UX.

Specific channel names, demographic distributions, relevance values, prices and budget numbers shown in the prototype are mock fixture data unless separately defined as business rules.

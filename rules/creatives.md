# Creative Rules

## Campaign creation — step 4: Загрузка креатива

- `BR-CRV-001` — Step 4 is **Загрузка креатива**.
- `BR-CRV-002` — The step contains a drag-and-drop style upload area.
- `BR-CRV-003` — The upload area includes a **Выбрать файл** button.
- `BR-CRV-004` — In the current wireframe, drag-and-drop and file selection are visual only and do not perform real file upload or validation.

## Campaign creative library

- `BR-CRV-005` — Campaign management has a **Креативы** action that opens a separate campaign creative-library page.
- `BR-CRV-006` — The creative-library page displays campaign media files as a list of cards.
- `BR-CRV-007` — A media-file card shows file name, media type, resolution, file format and file size; video files also show duration in seconds.
- `BR-CRV-008` — The creative-library page has a back action that returns to the campaign management page.

File names, resolutions, durations, formats and sizes currently shown in the creative library are mock fixture data. No file requirements, limits, validation rules or creative-assignment behavior are defined yet.
